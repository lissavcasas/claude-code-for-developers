# 🧠 1. Idea general del curso

* Curso **teórico + práctico** con:

  * ejercicios
  * tests
  * **proyecto final**
* Enfoque: usar **Claude Code como asistente de programación en entorno real**
* Se trabajará principalmente en:

  * **terminal / consola**
  * **VS Code (IDE recomendado)**

---

# ⚙️ 2. ¿Qué es Claude Code?

* Es un **asistente de programación avanzado** que:

  * vive en tu **máquina local (terminal/IDE)**
  * puede **leer, modificar y ejecutar código en tu proyecto**
* Diferencia clave con ChatGPT o Gemini:

  * ❌ No solo responde texto
  * ✅ **Interactúa directamente con tu código y archivos**

👉 Ejemplo:

* Le das una carpeta → analiza → crea archivos → corrige errores → ejecuta lógica

📌 Idea clave:

> Es como tener un programador trabajando contigo en tu proyecto.

---

---

# 🔑 5. Concepto clave: Tokens

* Un token ≈ palabra
* Se consumen en:

  * lo que escribes (input)
  * lo que responde (output)

👉 Consecuencia:

* Más interacción = más costo
* Necesitas **optimizar uso**

---

# 🧠 6. Estrategia de uso (muy importante)

📌 Claude NO es magia → necesitas saber usarlo bien

### Buenas prácticas:

* No hacer preguntas innecesarias
* Ser claro en prompts
* Limitar contexto

---

# 📁 7. Concepto CRÍTICO: `cloud.md`

* Es la **carpeta/proyecto donde Claude trabaja**
* Define:

  * qué archivos puede leer
  * dónde puede crear código

👉 Si NO lo defines:

* buscará en todo el sistema
* consumirá más tokens
* será más lento

📌 Idea clave:

> Es el "espacio de trabajo controlado" de Claude

---

# 🧰 8. Claude en VS Code vs Terminal

### VS Code (recomendado)

* ✔ Visual
* ✔ Ves archivos en tiempo real
* ✔ Más orden

### Terminal

* ✔ Más ligero
* ❌ Menos visual

📌 Conclusión:

> Para aprendizaje → VS Code
> Para producción → depende del caso

# 🤖 10. Tipos de modelos (MUY IMPORTANTE)

### 🔹 Haiku

* Barato
* Rápido
* Para tareas simples

### 🔹 Sonnet ⭐ (RECOMENDADO)

* Balance costo/calidad
* Ideal para programación

### 🔹 Opus

* Más potente
* Más caro
* Para tareas complejas

---

### 📊 Estrategia ideal:

* 10% Haiku
* 80% Sonnet
* 10% Opus

---

# 🧪 11. Comandos importantes

* `/model` → cambiar modelo
* `/clear` → limpiar contexto
* `/cost` → ver consumo
* `/compress` → reducir tokens
* `/diff` → ver cambios
* `/revert` → deshacer cambios

📌 Clave:

> `/compress` = ahorro de dinero
